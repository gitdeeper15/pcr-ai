# Analysis Templates — Research II

These templates operationalize the four research question families (A–D) for future empirical work. They are **structural templates**, not data. Each row corresponds to one representation observed in one system.

| Template | Purpose | Corresponds to |
|---|---|---|
| `function_matrix_template.csv` | Map each representation to the five functional units | Family A (RQ-A1, RQ-A2, RQ-A3) |
| `authority_matrix_template.csv` | Identify which of the five authorities is exercised | Family B (RQ-B1 – RQ-B6) |
| `lifecycle_path_template.csv` | Classify each representation into a lifecycle path | Family C (RQ-C1 – RQ-C5) |
| `rq_tracking_template.csv` | Track answers to the 20 research questions | Families A–D |

**Status:** No data has been entered. These templates are placeholders pending methodological scope determination (RQ-D2).
