## Note on Literature Review (2026-11-04)

Stage 2b of the literature review (Section 2) downgraded **L2 (Transformation)** from **Distinct** to **Reorganized**:

- Transformation as a *technical* stage is theorized (editing, moderation, re-ranking), but not as a *structural* stage.

**L6 (Re-origination)** remains **Distinct** — the recipient's production of a new representation is not theorized as a structural stage in any tradition.

The six-stage lifecycle is therefore Research II's **integrative contribution** (five stages reorganized from existing traditions) plus **one distinct stage** (L6 — Re-origination).

## 1. Purpose

This document traces the path of a representation through the five functions and the five authorities. It does not prescribe a single path; it specifies the structural stages through which a representation may pass, and the conditions under which different paths arise.

---

## 2. The Six Lifecycle Stages

| Stage | Description |
|---|---|
| 1. Origination | The representation is constituted from material. |
| 2. Transformation | The representation is modified, reshaped, or regenerated. |
| 3. Selection | The representation is included in or excluded from the presented set. |
| 4. Distribution | The representation is made available (or restricted). |
| 5. Reception | The representation reaches the recipient. |
| 6. Re-origination | The recipient may produce a new representation, entering the lifecycle again. |

These stages are analytical, not temporal. A representation may pass through all six or through a subset; the order may vary; some stages may be absent, repeated, or simultaneous.

---

## 3. The Canonical Path

The canonical path is the path through which a representation passes all six stages in sequence, with one entity performing each function:

```

Origination → Transformation → Selection → Distribution → Reception → [Re-origination → …]

```

This path is analytically clean, empirically rare, and useful as a baseline for comparison. It is a reference point, not a norm.

---

## 4. Alternative Paths

Five structurally distinct alternative paths are specified.

### Merged Path

Multiple stages are performed by the same entity:

```

[Origination + Transformation + Selection + Distribution] → Reception → [Re-origination → …]

```

Common in integrated platforms where a single service controls the full chain.

### Skipped Transformation

```

Origination → Selection → Distribution → Reception

```

Appears when the representation is presented as-is after origination.

### Skipped Selection

```

Origination → Transformation → Distribution → Reception

```

Appears when the presentation set is not curated, as in unfiltered chronological feeds.

### Distributed Origination

```

[Producer₁ + Producer₂ + … + Producerₙ] → Transformation → …

```

Appears in collaborative, multi-source, or composite representations.

### Iterative Re-origination

```

Origination → … → Reception → Re-origination → Transformation → … → Reception → …

```

Appears in recursively generated, remixed, or chained representations.

These five alternative paths are not exhaustive; they are structurally distinct reference points.

---

## 5. The Lifecycle and Authority

| Stage | Authority Typically Exercised |
|---|---|
| Origination | Production Authority |
| Transformation | Transformation Authority |
| Selection | Selection Authority |
| Distribution | Distribution Authority |
| Reception | (Recipient's Interpretive Authority) |
| Re-origination | Production Authority (in a new cycle) |

The mapping is typical, not necessary. An authority may be exercised outside its corresponding stage, and a stage may occur without its corresponding authority being fully exercised.

---

## 6. Structural Breaks in the Lifecycle

The lifecycle may be structurally interrupted at several points, each analytically significant because it reveals where authority is exercised to constrain the chain.

- **Interruption at Origination** — abandonment, restriction before completion, or failure to reach the transformation stage.
- **Interruption at Transformation** — direct presentation without transformation, process failure, or policy-based blocking of transformation.
- **Interruption at Selection** — exclusion from the presented set, sub-threshold ranking, filtering, or suppression.
- **Interruption at Distribution** — access restriction, geographic limitation, temporal unavailability, or retention failure.
- **Interruption at Reception** — failure of the recipient to encounter the representation, recipient disengagement, or structural barriers to access.

---

## 7. The Recipient's Interpretive Position

Reception is not a passive endpoint. The Recipient's Interpretive Authority (Section 4.3 of the Authority Structure) operates on the representation received and may confirm the representation's framing, contest it, produce an alternative interpretation, or lead to re-origination, returning to the lifecycle. The Recipient's interpretive position is therefore not determined by the earlier stages; it is structurally distinct from them.

---

## 8. The Lifecycle as Analytical Instrument

The lifecycle is not a description of how representations actually move; it is an instrument for examining which stages are present in a given system, which paths a representation takes, which authorities are exercised at each stage, where structural interruptions occur, and how the Recipient's interpretive authority operates. It is applied to specific systems, not derived from them.
